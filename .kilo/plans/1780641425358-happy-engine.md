Для реализации нужно добавить в `call_static_android.go`:
- `callInt(method)` — для `apiLevel()` (возвращает int, вместо GetSDKInt/apiLevel)
- `callStringString(method, arg)` — для getFileName (возвращает String)
- `callBooleanString(method, arg)` — для canListDirectory (возвращает boolean)
- `callVoidInt(method, arg)` — для setResult (опционально)

Все обёртки должны возвращать `error` (как существующие `callVoid`/`callVoidString`), чтобы вызывающий код мог обработать ошибку JNI.
