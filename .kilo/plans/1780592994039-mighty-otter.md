# Fix: EGL_BAD_SURFACE при onRestart на Android

## Корневая причина

В Fyne `android.go:455-463` (`mainUI`): когда NativeActivity уходит в фон и возвращается через
`onRestart` (без destroy), EGL surface становится невалидным, но `C.surface` остаётся non-nil.
Fyne продолжает `eglSwapBuffers` на мёртвом surface → `EGL_BAD_SURFACE`.

При `onCreate → onStart → onResume` (чистый старт) ошибки нет, т.к. EGL surface создаётся заново.

## Фикс: `onUserLeaveHint()` в GoNativeActivity.java

`onUserLeaveHint()` вызывается **только** при пользовательской навигации (Home, Recents, Back),
но **НЕ** при открытии файлпикера, браузера или системных диалогов из кода.
Это позволяет вызывать `finish()` без риска сломать файлпикеры.

### 1. `GoNativeActivity.java` — `onRestart` → `recreate()` на Android 9

Проблема: только на API ≤ 28 (Android 9), только при возврате из Недавних.
`onRestart` — точное место: Home→tap icon даёт `onCreate`, а Recents даёт `onRestart`.

```java
@Override
protected void onRestart() {
    super.onRestart();
    Log.d(TAG, "Java: onRestart");
    lifecycleEvent("restart");
    if (Build.VERSION.SDK_INT <= 28) {
        recreate();
    }
}
```

`recreate()` разрушает и создаёт activity заново: onDestroy → onCreate → onStart → onResume.
EGL surface создаётся с нуля — нет EGL_BAD_SURFACE.

## Результат

Пользователь нажимает Home/Recents → onUserLeaveHint → finish() → destroy → (возврат) → onCreate
→ свежий EGL surface → нет EGL_BAD_SURFACE.

Файлпикер открывается → onPause без onUserLeaveHint → finish() НЕ вызывается → файлпикер работает.
