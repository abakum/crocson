# Plan: Embed CLI mode into crocson GUI

## Status: IMPLEMENTED

## Goal

crocson работает как GUI и CLI:
- **Без аргументов** → GUI (как раньше)
- **Все аргументы — существующие файлы** → GUI (как раньше, добавляет в отправку)
- **Иначе** → CLI (`cli.Run()` из форка croc)

## Реализованные изменения

### 1. `main.go` — CLI dispatch ✅

- Добавлен import `"github.com/schollz/croc/v10/src/cli"`
- Функция `isCLIMode()` — определяет CLI vs GUI по аргументам
- В начале `main()`: если CLI → `cli.Run()` и выход, иначе `hideConsole()` и GUI

### 2. Платформенные файлы — `hideConsole()` ✅

- `for_windows.go` — `GetConsoleProcessList()`: если 1 процесс (запуск из explorer) → `FreeConsole()`, иначе (из терминала) — оставляем
- `for_unix.go` — пустая заглушка
- `for_darwin.go` — пустая заглушка

### 3. `cmd/syso/main.go` — генератор .syso ✅

Читает `FyneApp.toml` (Icon, Name, Version, Build, ID, Comment), конвертирует PNG→ICO, генерирует `resource_windows_amd64.syso` через `goversioninfo`.

Кэширование по mtime: если `.syso` свежее `.toml` и `.png` — ничего не делает.

### 4. `Makefile` ✅

- Добавлен таргет `syso`: `go run ./cmd/syso`
- Таргет `syso` добавлен в `.PHONY`

### 5. CI `.github/workflows/fyne.yml` ✅

Порядок шагов `build-windows`:
1. Install Fyne CLI (release only)
2. Decode P12 Certificate (release only)
3. Build Windows AppX package — `fyne release` (release only) → `crocson.appx`
4. **Build Windows console exe** — всегда, без условия: `go run ./cmd/syso` + `go build -ldflags=-s` → `crocson.exe` (console, с иконкой)
5. Upload — один шаг, `warn` на `.appx`

### 6. `go.sum` обновлён ✅

Добавлены `github.com/Kodeworks/golang-image-ico`, `github.com/chzyer/readline`, `github.com/schollz/cli/v2`.

## Не реализовано

### Makefile `windowsgui` / `mwindows` — всё ещё с `-H windowsgui`

Таргеты `windowsgui` и `mwindows` в Makefile не обновлены — всё ещё содержат `-ldflags="-s -H windowsgui"` и `-extldflags=-mwindows`.

Для CI это не важно (CI использует `go build` напрямую). Но для локальных сборок Windows через `make windowsgui` / `make mwindows` бинарник будет без консоли → CLI-режим не сможет писать в stdout/stderr.

**Решение:** убрать `-H windowsgui` и `-extldflags=-mwindows` из обоих таргетов (как в таргете `wsl`).

## Подтверждено работает

```bash
crocson --help                    # CLI справка croc
crocson --version                 # croc version v10.4.3
crocson send -h                   # справка send
crocson relay -h                  # справка relay
crocson nonexistent-file          # CLI receive mode
crocson                           # GUI (как раньше)
crocson существующий_файл         # GUI (как раньше)
make syso                         # генерация .syso (с кэшем по mtime)
```
