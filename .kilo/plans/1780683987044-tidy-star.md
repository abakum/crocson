# Plan: Keep date and deletion checkbox visible on Android in directory.html

## Problem
Mobile media queries in `directory.html` hide the date column (`.directory-listing .date`) on screens ≤768px and ≤480px. The deletion checkbox (`.del-chk`) is not currently hidden by CSS, but the date column is.

## Changes
In `directory.html`, remove `display: none` from `.directory-listing .date` in both media queries:

1. **Line ~295-297** (`@media max-width: 768px`): Remove the `.directory-listing .date { display: none; }` rule
2. **Line ~323-326** (`@media max-width: 480px`): Remove the `.directory-listing .date { display: none; }` rule

This will keep the date column visible on all screen sizes, including Android devices.
