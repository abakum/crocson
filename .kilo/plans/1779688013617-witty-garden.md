# Plan: Обновить генератор рецептов F-Droid

## Контекст

Форк `tools` (fyne CLI) поправлен — при `--release` без `--sign` Writer не пишет META-INF. APK выходит unsigned и уже выровнен. Это позволяет убрать `zip -d`, `zipalign` и зависимость от SDK build-tools.

## Изменения

### 1. Правка `metadata/generate_recipe.sh`

Заменить строки 87-91:

```bash
      - fyne package -os android/${ABI} --release
      - zip -d crocson.apk 'META-INF/*' --out crocson-${ABI}.apk
      - \$\$SDK\$\$/build-tools/\$(ls \$\$SDK\$\$/build-tools/ | sort -V | tail -1)/zipalign
        -f -p 4 crocson-${ABI}.apk crocson-aligned.apk
      - mv crocson-aligned.apk crocson-${ABI}.apk
```

на:

```bash
      - fyne package -os android/${ABI} --release
      - mv crocson.apk crocson-${ABI}.apk
```

### 2. Запуск генератора

```bash
bash metadata/generate_recipe.sh
```

Это перезапишет `metadata/com.github.abakum.crocson.yml` с обновлёнными блоками сборки.

### 3. Проверка

Убедиться, что в сгенерированном YML нет `zip -d`, `zipalign`, `SDK`, а каждый блок сборки заканчивается `mv crocson.apk crocson-${ABI}.apk`.

Также убрать `zip` из `sudo: apt-get install -y golang-go zip` → `sudo: apt-get install -y golang-go`.

### 4. Правка `.github/workflows/fyne.yml` — Android build step

Заменить цикл сборки внутри шага "Build with fyne package for Android targets" (строки 589-596):

```yaml
            fyne package -os $target --release
            if [ -f crocson.apk ]; then
                zip -d crocson.apk "META-INF/*" --out "crocson-${GOARCH}.apk"
                echo "Created APK: crocson-${GOARCH}.apk"
            else
```

на:

```yaml
            fyne package -os $target --release
            if [ -f crocson.apk ]; then
                mv crocson.apk "crocson-${GOARCH}.apk"
                echo "Created APK: crocson-${GOARCH}.apk"
            else
```

### 5. Правка `.github/workflows/fyne.yml` — Sign APK step

Заменить шаг "Sign APK" (строки 715-741):

```yaml
      - name: Sign APK
        run: |
          cd ${{ github.workspace }}/workspace/crocson

          echo "${{ secrets.ANDROID_SIGNING_KEY }}" | base64 -d > /tmp/keystore.jks

          BUILD_TOOLS="$ANDROID_HOME/build-tools/31.0.0"
          if [ ! -d "$BUILD_TOOLS" ]; then
            echo "Installing Android build tools 31.0.0..."
            yes | "$ANDROID_HOME/cmdline-tools/latest/bin/sdkmanager" "build-tools;31.0.0"
          fi

          for apk in crocson-*.apk; do
            echo "Aligning $apk..."
            "$BUILD_TOOLS/zipalign" -f -p 4 "$apk" "${apk}.aligned" && mv "${apk}.aligned" "$apk"
            echo "Signing $apk..."
            "$BUILD_TOOLS/apksigner" sign \
              --ks /tmp/keystore.jks \
              --ks-key-alias "${{ secrets.ANDROID_KEY_ALIAS }}" \
              --ks-pass "pass:${{ secrets.ANDROID_KEYSTORE_PASSWORD }}" \
              --key-pass "pass:${{ secrets.ANDROID_KEY_PASSWORD }}" \
              "$apk"
            echo "Verifying $apk..."
            "$BUILD_TOOLS/apksigner" verify -v "$apk"
          done

          rm -f /tmp/keystore.jks
```

на:

```yaml
      - name: Sign APK
        run: |
          cd ${{ github.workspace }}/workspace/crocson

          echo "${{ secrets.ANDROID_SIGNING_KEY }}" | base64 -d > /tmp/keystore.jks

          BUILD_TOOLS="$ANDROID_HOME/build-tools/31.0.0"
          if [ ! -d "$BUILD_TOOLS" ]; then
            echo "Installing Android build tools 31.0.0..."
            yes | "$ANDROID_HOME/cmdline-tools/latest/bin/sdkmanager" "build-tools;31.0.0"
          fi

          for apk in crocson-*.apk; do
            echo "Signing $apk..."
            "$BUILD_TOOLS/apksigner" sign \
              --ks /tmp/keystore.jks \
              --ks-key-alias "${{ secrets.ANDROID_KEY_ALIAS }}" \
              --ks-pass "pass:${{ secrets.ANDROID_KEYSTORE_PASSWORD }}" \
              --key-pass "pass:${{ secrets.ANDROID_KEY_PASSWORD }}" \
              "$apk"
            echo "Verifying $apk..."
            "$BUILD_TOOLS/apksigner" verify -v "$apk"
          done

          rm -f /tmp/keystore.jks
```

Убраны:
- `zipalign` — APK уже выровнен Writer'ом
- Динамический поиск build-tools — оставлен фиксированный `31.0.0` для apksigner (apksigner не влияет на воспроизводимость, т.к. CI-подпись отличается от F-Droid)
