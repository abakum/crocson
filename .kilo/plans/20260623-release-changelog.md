# План выпуска новой версии

Процедура выполняется каждый раз при выпуске новой версии приложения crocson.

## Входные данные
- Текущая версия берётся из поля `Version` в `FyneApp.toml` (например `1.11.67`).
- Предыдущая версия — тег `v<предыдущая>` в git (например `v1.11.66`), определяется как `git describe --tags --abbrev=0`.

## Локали (каталоги `metadata/<locale>/changelogs/`)
- `ru-RU` — источник (пишется первым)
- `en-US`
- `ja-JP`
- `tr-TR`
- `zh-CN`

## Шаги

### 1. Определить версию
- Прочитать `Version` из `FyneApp.toml` → `VERSION` (напр. `1.11.67`).
- Определить предыдущую: `git describe --tags --abbrev=0` → `PREV` (без префикса `v`, напр. `1.11.66`).

### 2. Собрать изменения и записать черновик в ru-RU
- Выполнить `git log v<PREV>..HEAD --oneline` (при необходимости `--no-merges`, `-U0`/`--stat`) для просмотра коммитов с прошлой версии.
- Проанализировать коммиты и сформулировать краткий список пользовательских изменений в том же стиле, что и в предыдущих чейнджлогах (по строке на пункт, с префиксами областей: `Android:`, `Настройки:`, `Приёмник:` и т.п.).
- Записать черновик в `metadata/ru-RU/changelogs/<VERSION>.txt`.

### 3. Дождаться правок пользователя
- Сообщить пользователю путь к файлу `metadata/ru-RU/changelogs/<VERSION>.txt` и попросить отредактировать его.
- **Остановиться и ждать**, пока пользователь не подтвердит, что ru-RU чейнджлог финализирован.

### 4. Перевести в остальные локали
- Прочитать финальный `metadata/ru-RU/changelogs/<VERSION>.txt`.
- Для каждой локали из `[en-US, ja-JP, tr-TR, zh-CN]` записать перевод в `metadata/<locale>/changelogs/<VERSION>.txt`, сохраняя:
  - то же число строк и порядок пунктов,
  - принятые в данной локали префиксы областей (см. существующие чейнджлоги, напр. `Android:`, `Settings:`/`設定:`/`Ayarlar:`/`设置:`, `Receiver:`/`受信:`/`Alıcı:`/`接收:`),
  - естественный для языка стиль перевода.

## Замечания
- Файлы чейнджлогов не содержат заголовков — только по одной строке на пункт изменений.
- Имя файла — это номер версии без префикса `v` и без ведущих нулей (напр. `1.11.67.txt`).
