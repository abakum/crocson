# Анализ: могли ли незакоммиченные изменения сломать диплинки

## Вывод: **Нет, незакоммиченные изменения не сломали диплинки.**

Но в логе видна **существующая ошибка** — `ActivityNotFoundException` в `handleIOTapped()`. Причина: `FLAG_ACTIVITY_REQUIRE_NON_BROWSER` исключает само crocson, т.к. его intent-filter содержит `CATEGORY_BROWSABLE`.

---

## Незакоммиченные изменения НЕ затрагивают диплинки

### 1. Удаление `notFinish`
- Удалена переменная + **весь обработчик** `case "pause":` → `finish()`
- Старый код: `notFinish=true` в `handleIOTapped()` → `finish()` не вызывался
- Новый код: `finish()` не вызывается никогда
- **Результат одинаковый**

### 2. Удаление `noRestart` / `restart()`
- `restart()` вызывался после send/recv, не при обработке диплинков
- Теперь: `ctc()` (context cancel) вместо `os.Exit(0)`

### 3. Удаление `ZhangHai`
- Workaround для файл-менеджера, не диплинки

### Маршрут диплинка — не изменён
```
onNewIntent() → processIntentData() → logIntentURI()  [Java — не изменено]
  ↓ JNI
intentURINotify() → uriFromIntent channel              [Go — не изменено]
  ↓
fromURI() — парсинг https://abakum.github.io/croc#...  [Go — не изменено]
```

## Реальная причина `ActivityNotFoundException`

`handleIOTapped()` в applinks.go:1040-1067:

```go
intent := &Intent{
    ...
    Flags: flagActivity(
        FLAG_ACTIVITY_SINGLE_TOP,
        FLAG_ACTIVITY_REQUIRE_NON_BROWSER,   // ← ПРОБЛЕМА
    ),
}
```

**Документация Android** для `FLAG_ACTIVITY_REQUIRE_NON_BROWSER`:
> *"it will not match any component that has the CATEGORY_BROWSABLE category set"*

**AndroidManifest.xml:41** — intent-filter для `https://abakum.github.io/croc.*`:
```xml
<category android:name="android.intent.category.BROWSABLE" />
```

**Следствие**: `REQUIRE_NON_BROWSER` исключает само crocson → `ActivityNotFoundException` → фолбэк на `BROWSER` → ссылка открывается в браузере вместо crocson.

**Это не связано с незакоммиченными изменениями** — код `handleIOTapped()` идентичен в обеих версиях.

## План исправления

### Проблема
`handleIOTapped()` использует `FLAG_ACTIVITY_REQUIRE_NON_BROWSER` (applinks.go:1054).
Android docs: *"will not match any component that has the CATEGORY_BROWSABLE category set"*.
Crocson's manifest (AndroidManifest.xml:41) **должен** иметь `CATEGORY_BROWSABLE` — без него App Links (`autoVerify="true"`) не работает.

**Результат**: crocson исключает сам себя из интента → `ActivityNotFoundException` → фолбэк на браузер.

### Шаг 1: Вернуть CATEGORY_BROWSABLE в AndroidManifest.xml

`CATEGORY_BROWSABLE` **обязателен** для App Links. Убрать комментарий.

### Шаг 2: Исправить handleIOTapped() в applinks.go:1049-1067

Убрать `FLAG_ACTIVITY_REQUIRE_NON_BROWSER` и мёртвый фолбэк на `BROWSER`:

**Было:**
```go
intent := &Intent{
    Data:   strings.TrimPrefix(qr.link.URL.String(), qr.link.URL.Scheme+":"),
    Scheme: qr.link.URL.Scheme,
    Flags: flagActivity(
        FLAG_ACTIVITY_SINGLE_TOP,
        FLAG_ACTIVITY_REQUIRE_NON_BROWSER,
    ),
}

if err := OpenURL(intent.String()); err == nil {
    NewToast(qr.window, "OK").Show()
    return
}

intent.SetFlags(BROWSER)
if err := OpenURL(intent.String()); err != nil {
    qr.app.SendNotification(fyne.NewNotification("Error", err.Error()))
}
```

**Стало:**
```go
intent := &Intent{
    Data:   strings.TrimPrefix(qr.link.URL.String(), qr.link.URL.Scheme+":"),
    Scheme: qr.link.URL.Scheme,
    Flags:  flagActivity(FLAG_ACTIVITY_SINGLE_TOP),
}

if err := OpenURL(intent.String()); err != nil {
    qr.app.SendNotification(fyne.NewNotification("Error", err.Error()))
}
```

### Шаг 3: Вернуть верификацию домена через adb

```bash
adb shell pm set-app-links --package com.github.abakum.crocson STATE_SUCCESS abakum.github.io
adb shell pm set-app-links-user-selection --user 0 --package com.github.abakum.crocson true abakum.github.io
```

Или пользователь может нажать кнопку **"Allow"** в приложении (applinks.go:350) → откроется `APP_OPEN_BY_DEFAULT_SETTINGS` → включить "Supported links".

### Ожидаемый результат после фикса
- **Домен verified + Enabled** → Android автоматически откроет ссылку в crocson (через App Links, без чузера)
- **Домен verified + Disabled** → чузер или браузер → пользователь может нажать "Allow" → включить
- **Домен не verified** → чузер с crocson и браузерами → выбрать "Always"
