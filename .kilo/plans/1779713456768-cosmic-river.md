# Plan: srclib + fdroid4.yml updates

## 1. Создать файл srclib в репозитории crocson

Создать `metadata/srclibs/abakum-fyne-tools.yml`:
```yaml
RepoType: git
Repo: https://github.com/abakum/tools
```

## 2. Обновить `fdroid4.yml` — добавить вход `srclibs` для условного копирования

Добавить в `workflow_dispatch.inputs`:
```yaml
srclibs:
  description: 'Include srclib definitions in MR'
  required: false
  default: 'false'
  type: choice
  options:
    - 'false'
    - 'true'
```

В шаге "Create Merge Request to fdroiddata", после копирования changelogs, добавить условный блок:
```bash
# Copy srclib definitions (only on first registration)
if [ "${{ github.event.inputs.srclibs }}" = "true" ]; then
  mkdir -p srclibs
  cp "${{ github.workspace }}/metadata/srclibs/"*.yml "srclibs/"
fi
```

И обновить `git add` чтобы включать srclibs:
```bash
git add "metadata/${APP_ID}.yml" "metadata/${APP_ID}/" srclibs/
```

## 3. Итого файлы для изменения

- **Новый**: `metadata/srclibs/abakum-fyne-tools.yml` — определение srclib
- **Изменить**: `.github/workflows/fdroid4.yml` — добавить input `srclibs`, условное копирование
- **Уже изменён**: `metadata/generate_recipe.sh` — использует srclib (сделано ранее)
