crocson — croc для Android, Windows, Linux, macOS.

Передача файлов от отправителя получателю
- Через ретранслятор без проброса портов
- Десктоп: Drag-and-drop, командная строка, stdin pipe, в очереди только ссылки на файлы и каталоги
- Android: «Поделиться» и «Открыть с помощью» из файловых менеджеров

WebDAV - передача файлов в обе стороны
- Встроенный сервер HTTP/HTTPS
- Просмотр файлов через браузер, потоковое аудио/видео
- Проброс через зашифрованный туннель

Чат
- Вебчат с сеансовой историей
- Видеозвонки, видеосообщения, демонстрация экрана десктопа
- Серверная запись веб-камеры/микрофона/скриншотов (WebM/MP4/PNG) с публикацией в чат

Безопасность
- Сквозное шифрование (PAKE), одноразовые пароли (TOTP)
- Секрет из поля ввода или CROC_SECRET
- Выбор эллиптической кривой, пароль ретранслятора не раскрывается другой стороне

QR-код и Deep Links
- Генерация/сканирование QR-кодов, поддержка сканеров Android
- Deep Links для настроек и WebDAV

Профили ретрансляторов
- Переключение, локальное управление из GUI или CLI
- Прокси: SOCKS5 (Tor), HTTP

Настройки передачи
- .gitignore, перезапись файлов, сжатие, защита от удаления по ссылке WebDAV
- Мультиплексирование, ZIP папок, ограничение скорости

Интерфейс
- Темы: system/light/grey/dark/black
- Выбор шрифта, 5 языков

CLI режим
- Pipes, отправка текста, возобновление передач, тихий режим
